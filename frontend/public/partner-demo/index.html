Pageturner Books

A deliberately unrelated site. It knows nothing about Actuo.

What this page is for

This page registers its own WebMCP tools — search_books and get_book_price — and exposes them to Actuo's origin via exposedTo. Actuo's Copilot discovers them with getTools({ fromOrigins }) and runs them through executeTool().

Nothing here is Actuo-specific, which is the point: the Copilot is site-agnostic, so it can drive any WebMCP-enabled page.

Requires Chrome with the WebMCP flag on (chrome://flags/#enable-webmcp-testing). Cross-origin tools cannot be polyfilled — the polyfill rejects exposedTo with NotSupportedError.
